# Retired docs

- **Date retired:** 2026-11-23
- **Old location:** `server/docs/`
- **Archived to:** `server/docs-retired/`
- **Superseded by:** `docs/` (this tree)

The 18 files in `server/docs/` (00-overview through 17-safe-code, plus `reviews/`) were the original design notes written alongside the server code. They have been superseded by the structured docs tree rooted here at `docs/`. Where the two disagreed, `docs/` was already the winner (see `MIGRATION.md` for the file-by-file map). The old files are preserved in `server/docs-retired/` for reference and historical context; no active tooling or rule points at that path any longer.
