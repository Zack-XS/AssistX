# Android app

The app is in `android/`. It shows the assistant's page in a WebView and adds native parts: alarms, notices, voice, location, listening, health, phone actions.

- [App structure](app-structure.md): files, screens, permissions, sounds.
- [Talking to the server](talking-to-server.md): tokens, live connection, uploads, which screen calls which route.
- [Updates and release](updates-and-release.md): build, publish, install, update.

To set it up, see [Run the Android app](../getting-started/run-android.md).
