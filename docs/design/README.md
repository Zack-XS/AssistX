# Design

The AssistX design language. It is fluid, minimal and compact. It works on a phone and on a desktop. It adapts to what you are doing, it moves smoothly, and its icons are soft and round. It looks hand made, with little colour.

It builds on what the app has today: the page `server/examples/dummy-client/index.html` (shown in the app's WebView) and a few native Kotlin screens. See [App structure](../android/app-structure.md).

Status: the language is written. The app follows most of it. Each page ends with **Gaps**: where the app differs today. The work to close them is in [Design language rollout](../plans/design-language-rollout.md).

- [Principles](principles.md): The few rules every screen follows.
- [Color](color.md): Colour tokens for light and dark, and how colour is used.
- [Typography](typography.md): The font, the type scale and how text is set.
- [Spacing and layout](spacing-and-layout.md): Compact spacing, corner sizes, the grid and layouts from phone to desktop.
- [Motion](motion.md): Durations, easing, springs, page moves and reduced motion.
- [Icons](icons.md): One soft, round icon set, sizes, states and animated icons.
- [Components](components.md): Buttons, cards, chat bubbles, lists, sheets, inputs and notices.
- [Smart UI](smart-ui.md): How screens adapt to time, place and what you are doing.
- [Accessibility](accessibility.md): Contrast, touch size, text size, screen readers and motion.
- [Tokens](tokens.md): One table of design values for the app page, Android and the docs site.
- [Screens](screens.md): The four tabs, where every screen lives, the states each screen shows, and how to add one.
