# Quality

These pages say what a good change looks like. Every change, by a person or an AI agent, must meet them.

Start with [Quality bar](quality-bar.md). If you are an AI agent, also read [Agents checklist](agents-checklist.md).

- [Quality bar](quality-bar.md): What "done" means: tests, review, lint, no secrets, small changes.
- [Safety](safety.md): The safety rules every change must keep.
- [Logging](logging.md): Every change adds logs. What to log, levels, fields, and what never to log.
- [Testing](testing.md): What to test, how, and which tests each kind of change needs.
- [Performance](performance.md): Keep the server quick and small, and the model calls cheap.
- [Android battery](android-battery.md): How the app stays light on battery, and the gaps.
- [Code review](reviews.md): The checklist a reviewer runs on every change.
- [Writing docs](writing-docs.md): Format, front matter, style, where pages go, and keeping docs in sync.
- [Agents checklist](agents-checklist.md): Rules AI agents must follow when they change the code.

These pages build on [Contributing](../contributing/README.md) and [Security](../security/README.md). They link to those pages and do not copy them.
